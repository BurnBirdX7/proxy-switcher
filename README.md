# (Bare-bones) ProxySwitcher

Just bare-bones extension for switching between pre-configured proxy modes.

To cycle through proxy modes: left-click on the extension icon.  
To select needed modes: right-click → Manage Extension → Options.

Proxy settings affect private browsing, so this extension requires permission to run in Private windows.

## Notes
**Source code:** https://github.com/BurnBirdX7/proxy-switcher  
**Note:** Extension uses [Material Symbols](https://github.com/google/material-design-icons).

## Scripts

`npm run build` - creates ZIP archive for upload to [AMO](https://addons.mozilla.org).  
`npm run start` - starts Firefox Developer Edition with the extension enabled.  
`npm run lint` - runs linter.
